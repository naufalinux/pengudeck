# hermes-dash

Web dashboard for Hermes agents. Kanban board view plus opt-in cleanup Settings (one toggle, ages, board checkboxes), localhost only (`127.0.0.1:8788`).

See [Kanban retention](docs/RETENTION.md) for the standalone cleanup script, 30/180-day defaults, dry-run, backup and scheduler safeguards. Automatic cleanup is disabled until explicitly enabled in Settings.
